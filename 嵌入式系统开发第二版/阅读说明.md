# 阅读说明

本包为 Elecia White《Making Embedded Systems: Design Patterns for Great Software》第二版的中文全译文与配套资源。

- 完整中文译文.md：全书合并 Markdown。
- chapters/：分章 Markdown、前置内容、索引与后置内容。
- assets/：译文引用的原图、代码和公式图等；请与 Markdown 保持目录关系。
- 统一术语表.md / .csv：术语和语境说明。
- 审校报告.md、待确认问题.md：实际检查范围、源文件限制与原书疑点。
- 全书结构与处理清单.md、进度记录.md：范围与完成状态。

中文 PDF 作为独立附件提供，含可点击中文目录和书签；索引同时保留原书页码及译本跳转。Markdown 的原书页码链接定位到相应译文，实际显示取决于阅读软件对 HTML 锚点的支持。

原书代码的可见字符与英文注释保留；原书自身疑误没有静默修正。保留的〔待确认〕见问题清单。译文优先表达原书内容，未据外部现行资料更新原书。原始英文 PDF 保留不变。
