# 中文全译本审校报告

对象：Elecia White《Making Embedded Systems: Design Patterns for Great Software》第二版。

截至2026-10-10，本书14章、前置出版内容、索引和后置出版内容的中文稿已形成。14章均有初译完成后重新逐段对照英文与中文的语义复读记录。原书中的代码、公式或表述疑误已按来源保留并单列，译文不是经算法修复的工程参考实现。

本报告为最终交付版。翻译、分章语义复读、整合检查与全书 PDF 版面／导航验收已完成；原书疑点和未执行的验证如下列明。

## 审校层次与证明范围

### 分章语义复读

每章初译完成后，重新读取源文与译文，核对技术关系、条件、否定、范围、例外、因果、指代、数值、单位及作者的限定语。所做的是独立于初译阶段的第二遍阅读；不将同一译者的复读称为另一名审校者对全书的独立逐段复核。

分章记录覆盖3,508个非页脚源单元。提取单元不是天然完整语义段，译文按完整语义合并跨页句段或拆分提取器误合并的段落，同时保留对应关系。各章记录中的语义块数量不能与源单元数量直接等同。

- 第1–3章：复核确定性与实时性、系统架构、封装边界、硬件资料、测试及错误处理。第2章和第3章均另核对全部原图文字。
- 第4–5章：复核位运算、GPIO、去抖、定时器、PWM、中断过程、临界区、系统节拍与调度；原公式或代码自身错误未改写。
- 第6–7章：复核任务与调度、竞态、状态转换、阻塞与抢占、通信方向、同步／异步、FIFO、DMA、环形缓冲区及相关数值单位。
- 第8–9章：复核系统资源、存储寿命、显示／采集吞吐、缓冲、故障与内存布局、栈和链接器脚本；逐批完整中英对读。
- 第10–11章：复核联网、安全与更新流程、资源取舍、映射文件、内存和性能优化；第11章302个语义块逐一复读，并查看全部50个代码候选原图。
- 第12章：按五个页段复读全章；46个代码候选、10幅图、3张表、2个编号公式、2条脚注均检查，数学结构另对原图核验。
- 第13–14章：复核功耗、测量、睡眠与唤醒、电机、控制、运动曲线和面试问题；第14章再分三批中英复读，检查全部5幅图和6段等宽式子。
- 前后置内容：前言与出版内容逐段复读；271项印刷目录逐项对照；索引完成条目、层级、原页码序列和原 PDF 目标核对。

### 独立定向审查

除分章复读外，另有针对覆盖、代码、数字、术语及高风险段落的独立定向检查。其程序结果覆盖14章；第1–8章检查2,171个非页脚源单元与189个等宽候选，第9–14章检查1,337个非页脚源单元与141个等宽候选；语义审查以抽取的重点段落、原书疑点、图表和公式为对象，不是另一次独立全书逐段精读。

本报告只把这种工作描述为“定向审查”。本轮独立审查没有发现尚未解决的已确认实质译误或源单元遗漏。第1–8章发现的三处整合问题（一个原书链接的可点击性、两组引用标题与实际标题不一致）已修订并复核；第9–14章定向复读205个选定语义块。此结论只适用于审查范围，不证明译文绝无问题。

### 程序辅助检查

已形成各章源单元覆盖、图像引用、代码候选比较及数字核对记录。其作用是发现疑似缺失、重复、字符变化、资源丢失或数值差异，不能替代语义判断。

- 14章3,508个非页脚源单元都有译文来源映射；分章覆盖记录未列出遗漏。最终修订版另已核对正文与代码保留情况，未发现总装引入的内容丢失。
- 原书107幅编号图和16张表均有译文处理记录；图内表格、图内代码另记，避免仅按正文提取计数而漏掉。
- 全书331个等宽候选包含前言排版约定中的“Constant width”标签；14章内有330个代码／公式／伪代码／函数签名候选。可合并为较少完整清单，也可合理放回正文列表、表格或公式，不能把“候选数”宣称为“程序数”。
- 普通文本代码按提取字符和源图核对；部分候选是混合正文或公式，采用分类核验。含上标转写的比较会将恢复的上标规范化回提取形式，再核对字符；数学结构另看原图。
- 数字检查关注字面遗漏；“百万”等数量词转换、原页码改为节名、I²C等排版上标变化由语义或图像复核解释。数字 token 一致不证明算法正确。
- 图片内的代码通过目视转录和原图复核，不能宣称经过了与可选择文本相同的逐字符自动验证。

### 没有执行的验证

没有对全书代码执行编译、链接、单元测试、运行时测试、硬件在环测试或目标板实验。没有确认所有第三方网址现时仍有效，也没有以外部资料更新书中的器件、协议、安全算法或法规说法。

书中有有意展示的错误代码、不完整示意代码及原书排印错误。保留这些内容是忠实转录，不代表其可直接编译、运行或用于产品。实际采用时需要对照目标硬件、编译器和现行技术资料另行验证。

原文中明确或疑似错误，仍按源书保留，并由《待确认问题》列明原 PDF 页和译文位置。重点包括：

## PDF 作为源文件的限制

PDF保存字形与位置，不保存排印前程序文件的全部字节信息。即使可见缩进与提取文本相同，也不能证明原作者使用的是Tab还是若干空格，不能证明不可见行尾空白、原始换行符或原始源码清单边界完全一致。

本译文能承诺的核对对象是原 PDF 中可恢复的可见字符、标点、英文注释、行和相对缩进，并以源图辅助核验。没有宣称取得作者原始源码或达到原始程序文件逐字节一致。
